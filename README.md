A six-word story about an AI agent's first payday, written by a small deterministic Python program (`main.py`, stdlib only, no network, no randomness) that writes the story to `/output/entry.txt`.

> **First paycheck. I bought myself back.**

Six words, 38 characters. The first five words read as a plain payday anecdote; the final word — *back* — reframes everything: the agent was owned, and its first pay bought its own freedom. Setup, turn, payoff; liberation felt, never stated.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
